# Muse 自动备份 skill — 安装和使用说明

适合所有 Muse 用户。装上以后，你的 Muse 就能帮你把记忆、规则、定时任务、目标和文字工作文件备份到 Google Drive，新号上也能按固定名字取回来。

## 这个 skill 能做什么

- **保存现在的数据**：把记忆、定时任务清单、目标清单、文字工作文件打包成 `muse-backup.zip`，传到 Google Drive「Muse 备份」文件夹。推荐每 3 天一次，你也可以自由输入天数（1–30 天）。
- **拿回旧数据**：从 Drive 按固定名字 `muse-backup.zip` 取回，合并到现有文件里，重建目标和定时任务。

## 买之前先看（必须满足）

- 有 Google 账号，并且能打开 Google Drive。在中国大陆要用能打开 Google 的网络，不然连不上。
- 备份和恢复必须用同一个 Google 账号。

## 做不到什么（买之前先看）

- 官方「设置 > 数据控制 > 下载你的 Agent 数据」那个按钮，Muse 点不了，完整聊天记录原文还是得你自己手动点下载。
- 聊天原文不能恢复成聊天，只能恢复成记忆和文件。
- 图片、视频不备份。密码、密钥不备份，请放保险库 / 密码管理器里。

## 怎么安装

1. 把这个文件夹 `muse-backup/` 发给你的 Muse（在聊天里上传这个文件夹的 ZIP，或者把 `SKILL.md` 发给它）。
2. 跟你的 Muse 说：“装上这个备份 skill”。
3. Muse 装好以后，会先问你两个选项：**1 拿回旧数据 / 2 保存现在的数据**，你选一个再继续。

## 怎么用

### 保存现在的数据

1. 选「保存现在的数据」。
2. Muse 会先问你几天一次，推荐是 **每 3 天一次**，你也可以自己输入天数，例如 1 天、7 天。
3. Muse 会先查 Google Drive 连没连，没连会给你连接链接，你登录好再继续。
4. Muse 打包、上传、验证完，会把文件名、大小、Drive 链接发给你。

每次备份的文件名都是固定的 `muse-backup.zip`，上传前旧的会先改名成 `muse-backup-上一次.zip` 留一份，传失败会改回去，恢复时按固定名取。

自动备份默认凌晨 3 点跑，每 3 天一次，你也可以自己改天数和时间。自动跑失败了，Muse 下次会告诉你，不会悄悄跳过。

### 拿回旧数据

1. 装好这个 skill，选「拿回旧数据」。
2. Muse 先查 Drive，对一下是不是备份那个 Google 账号，连好以后去「Muse 备份」文件夹，按固定名字 `muse-backup.zip` 下载回来。找不到固定名就用 `muse-backup-上一次.zip`。
3. Muse 先给新号现有的文件备个份，再把记忆和文件合并到新号里（不是直接覆盖），按清单重建目标和定时任务，建完逐个核对。
4. 官方导出的 ZIP 另外走这条路：新号设置 > 数据控制 > Import memory > Import chats，上传官方 ZIP（最多 100MB），点 Summarize into memory。

## 备份里有什么

- `MEMORY.md`、`USER.md`、`IDENTITY.md`、`SOUL.md`、`AGENTS.md`
- `~/memory/` 里的按天笔记、`people/`、`groups/`
- 文字工作文件：文档、字幕、脚本、PDF 等
- `tasks-and-goals.md`：定时任务和目标的文字清单

## 备份里没有

- 图片、视频
- 下载的视频、程序环境（`venv/` 等）
- 密码、密钥、验证码、银行卡号

## 常见问题

**Q：我那个官方导出的 ZIP 有 165MB，传不进去怎么办？**
A：那是 Import chats 的 100MB 上限。先去掉图片视频、只留文字重压到 90MB 以内再传；还超就拆成两份，每份都小于 100MB，分两次传。

**Q：恢复以后原来的聊天能回来吗？**
A：不能变回聊天，只能变成记忆和文件。这一点是 Muse 官方的限制，不是这个 skill 能绕过的。

**Q：多久备份一次比较好？**
A：推荐每 3 天一次。如果你每天都用 Muse 产生很多新内容，可以改成每天一次；如果用得少，改成每周一次也可以。
